## Description
The data and notebook contained in this repository foster the reproducibility of the following paper: 
*  J.-A. Micoulaud-Franchi, V. P. Martin, J. Coelho, L. Imbault, E. Béquignon, J. Chambe, C. Quiles, P. Philip, F. Gagnadoux, A. Prigent, F. Roche, J. Texereau, and S. Baillieul, “Patient reported outcomes measures in OSA: A content overlap analysis using the Jaccard index,” [Under review]
